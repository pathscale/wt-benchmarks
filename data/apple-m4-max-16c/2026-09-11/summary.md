# WorkTable benchmark run

Generated by `scripts/run-all.sh`, 9 repetitions per cell.
Raw rows are in `target/benchmark-rows/`; every table below is
`summarize-grid` over one of those files and nothing was typed by hand.

A cell is compared only against the cell differing in one thing, the
runtime. Where the ranges overlap no percentage is printed: the table
says `within noise` and gives the spread, because a percentage a
second run would reverse is worse than none.
